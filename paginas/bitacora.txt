VERSION 2.0 - MIGRACION RESPONSIVE Y COMPONENTES

Implementado:
- Hoja externa styles.css consolidada con variables CSS, Nunito Sans de Google Fonts,
  colores heredados, clases propias, estados hover/focus y reglas responsive.
- Bootstrap 5.0.2 y Bootstrap Icons se cargan por CDN en las cuatro paginas.
  Bootstrap se carga antes de styles.css para que las reglas propias puedan
  personalizar sus componentes.
- La navegacion colapsable, llamadas a la accion y pie de pagina son consistentes
  en inicio, recorridos, servicios y formulario.
- Inicio usa la grilla responsive de Bootstrap y conserva el carrusel de servicios.
- Las rutas usan CSS Grid adaptable (auto-fit/minmax); cada tarjeta usa Flexbox
  para alinear su contenido y mantener la accion al pie.
- La flota usa la grilla de Bootstrap: una columna en movil, dos en pantallas
  pequenas/medianas y cuatro en escritorio. Las tablas de tarifas y bicicletas
  usan tabla Bootstrap dentro de un contenedor responsive.
- La seccion Beneficios de inicio se compone con clases utilitarias de Bootstrap.
- El formulario tiene cinco campos obligatorios con feedback visual, una alerta
  descartable y un modal para confirmar los terminos antes de enviar.
- El encabezado, menu y pie se alinean con Flexbox; las tarjetas adaptan el
  contenido con Flexbox y el catalogo usa Grid. Se combinan porque Grid organiza
  filas/columnas de tarjetas y Flexbox distribuye elementos dentro de cada tarjeta.
- Se usa una media query propia para pantallas pequenas; Bootstrap aporta los
  breakpoints de grilla para tablet y escritorio. Las imagenes de contenido son
  fluidas; la portada de inicio es un fondo que se muestra con contain para evitar
  recortar la ilustracion.
- Documentacion oficial consultada para grillas, utilidades, formularios,
  alertas, modales y navbar:
  https://getbootstrap.com/docs/5.0/layout/grid/
  https://getbootstrap.com/docs/5.0/utilities/spacing/
  https://getbootstrap.com/docs/5.0/forms/validation/
  https://getbootstrap.com/docs/5.0/components/alerts/
  https://getbootstrap.com/docs/5.0/components/modal/
  https://getbootstrap.com/docs/5.0/components/navbar/
  Iconos:
  https://icons.getbootstrap.com/

Comparativa final (datos visibles en los HTML):
- Inicio: antes mostraba tres tarjetas simultaneas; ahora son tres diapositivas
  navegables, y la introduccion/presentacion se apilan o se muestran en dos
  columnas segun el breakpoint.
- Recorridos: catalogo de 3 rutas; tarjetas en Grid adaptable. La flota contiene
  4 tipos: Montanera, BMX, bicicleta electrica y triciclo electrico.
- Tarifas: la tabla conserva 5 modalidades. Alquiler por horas muestra
  $8.000/$12.000/$17.000 por hora; alquiler por dia, $35.000/$50.000/$80.000.
  Los recorridos muestran tres valores por paquete: Medallo a Pedal
  $45.000/$60.0000/$90.000; Conexion urbana $65.000/$80.000/$100.000;
  Expedicion al limite $85.000/$100.0000/$120.000.
- Formulario: 5 campos obligatorios (nombre, correo, telefono, documento y tipo
  de bicicleta), validacion visual, alerta y confirmacion mediante modal.
- Los tres precios escritos como $60.0000 y $100.0000 parecen tener un cero
  adicional. Tambien hay tres valores por tarifa sin indicar a que tipo de
  bicicleta corresponde cada uno. Se conservaron los datos existentes y deben
  confirmarse antes de corregirlos; no se infirio una asociacion de precios.
- El formulario es una interfaz estatica: su accion actual envia por GET a
  servicios.html; no hay servidor que almacene reservas.

ACTUALIZACION - NAVBAR, CATALOGO Y BENEFICIOS

- Se actualizo el CDN de Bootstrap a 5.3.8 en las cuatro paginas para usar la
  version requerida por la practica. Se conserva integridad SRI en CSS y JS.
- La navbar usa navbar-expand-lg: el boton collapse aparece debajo de 992 px y
  los enlaces quedan visibles desde lg. Cada pagina principal identifica su
  enlace actual con .active y aria-current="page". El bundle se incluye una vez
  por documento antes de </body>.
- Se aplican botones primarios para reservar y botones outline para consultar;
  se usan btn-lg para la accion principal de navbar y btn-sm para consulta.
- La flota de Recorridos ahora incluye cuatro fichas con datos disponibles en
  la tabla. El enlace Reservar lleva el tipo de bicicleta al formulario, que lo
  preselecciona. Se agrego BMX a las opciones del formulario.
- Bajo la flota se agrego la seccion "¿Por qué Rueda Libre?" y su franja final
  usando exclusivamente clases/utilidades Bootstrap, sin clases CSS propias ni
  atributos style. La decoracion se oculta en movil y aparece desde md.

Clases consultadas en la documentacion oficial de Bootstrap 5.3:
- row-cols-lg-4: distribuye cuatro columnas a partir del breakpoint lg.
- g-3: aplica separacion uniforme entre columnas/filas de una grilla.
- fs-5: establece un tamano de texto del sistema tipografico de Bootstrap.
- fw-bold: aplica peso de fuente negrita.
- text-primary: aplica el color de texto primario del tema.
- d-none d-md-block: oculta el elemento en movil y lo muestra desde md.
- flex-column flex-md-row: apila el contenido en movil y lo ordena en fila
  desde md.
- gap-4: separa elementos de un contenedor flex/grid usando el espaciado.
